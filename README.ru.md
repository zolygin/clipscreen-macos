## Описание

**Clipscreen** — это быстрая нативная утилита для macOS, написанная на чистом Swift и AppKit. Она живёт в строке меню, не занимает место в Dock и хранит последние 100 записей буфера обмена.

Нажмите **⌥⌘V**, выберите нужную запись стрелками или начните вводить текст для поиска, и нажмите **Enter** — Clipscreen вернётся в исходную программу и автоматически вставит выбранный фрагмент.

## Возможности

- **Мгновенный вызов и вставка**: глобальный хоткей `⌥⌘V` открывает историю; нажатие `Enter` вставляет запись напрямую в активное поле приложения.
- **Поддержка разных типов данных**: сохраняет обычный текст, форматированный текст (RTF), полноразмерные изображения (с автоматическим созданием PNG-миниатюр) и ссылки на файлы из Finder.
- **Быстрый поиск**: фильтрация списка на лету по тексту или названию приложения-источника.
- **Кнопка скриншота**: иконка камеры (`⌥⌘4`) в шапке окна запускает интерактивное выделение области экрана с автоматическим сохранением снимка сразу в буфер и историю Clipscreen.
- **Единые иконки**: оригинальные SVG Lucide для истории, поиска, строки меню и редактора скриншотов, включённые в приложение вместе с лицензией.
- **Закрепление**: Pin находится справа; `⌘P` закрепляет выбранную запись, `⇧⌘P` включает фильтр закреплённых.
- **Настройки аннотаций**: толщина по правому клику на инструменте или готовой фигуре; одинаковые контурный и заполненный квадраты; многоцветная кнопка произвольного цвета; Undo/Redo для изменения толщины.
- **Draggable-окно**: окно можно свободно перемещать мышью за шапку; выбранное положение сохраняется между вызовами.
- **Нативный дизайн**: использует системные материалы macOS (Liquid Glass на macOS 26, стандартное размытие AppKit, поддержка режима пониженной прозрачности), плавно переключается между светлой и тёмной темами.
- **Никакого лишнего веса**: без Electron, сторонних фреймворков и сетевых зависимостей.
- **Безопасность и приватность**: работает на 100% локально. Пароли из менеджеров паролей (1Password, Bitwarden, KeePass, `org.nspasteboard.ConcealedType`, `TransientType`, `AutoGeneratedType`) автоматически игнорируются и не сохраняются на диск.

## Горячие клавиши

| Сочетание | Действие |
| --- | --- |
| `⌥⌘V` | Открыть или скрыть панель истории Clipscreen |
| `↑` / `↓` | Перемещение по записям |
| `Tab` / `⇧Tab` | Переключение записей сверху вниз / снизу вверх |
| `Enter` | Вставить выбранную запись в активное приложение |
| `Пробел` | Выбрать / просмотреть запись |
| `⌘⌫` | Удалить выбранную запись из истории |
| `⌥⌘4` / 📷 | Интерактивный скриншот области экрана прямо в буфер |
| `Esc` | Закрыть панель без вставки |

## Системные требования

- **Операционная система**: macOS 13.0 (Ventura) или новее.
- **Архитектура**: Apple Silicon (`arm64`) или Intel (`x86_64`).
- **Инструменты сборки**: Xcode или Command Line Tools (`swiftc`).

## Сборка и установка

Clipscreen собирается локально за считанные секунды:

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/kirillzolygin/clipscreen-macos.git
cd clipscreen-macos

# 2. Соберите приложение
bash scripts/build-app.sh

# 3. Запустите Clipscreen
open .build/Clipscreen.app
```

> **Совет:** Для постоянного использования переместите `Clipscreen.app` в папку `/Applications` перед выдачей системных разрешений и настройкой автозапуска.

### Первый запуск и разрешения

1. **Доступ к буферу обмена**: при первом запросе macOS разрешите постоянный доступ, чтобы Clipscreen мог отслеживать новые копирования в фоновом режиме.
2. **Универсальный доступ (для автовставки по Enter)**: включите Clipscreen в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.
   *(Без этого разрешения выбор записи по Enter скопирует её в буфер, и вставить её можно будет обычным `⌘V`).*
3. **Автозапуск**: по правому клику на значок Clipscreen в строке меню macOS можно включить автозапуск при входе в систему.

## Хранение данных и конфиденциальность

- **Только локальное хранение**: все данные лежат в папке `~/Library/Application Support/Clip/`. Никаких серверов, телеметрии, аналитики или сетевых запросов.
- **Права доступа**: директория создаётся с правами только для владельца (`0700`), а бинарные файлы записей — с правами `0600`.
- **Защита паролей**: данные с системными маркерами сокрытия (`ConcealedType`, `AutoGeneratedType`, `TransientType`, 1Password) отсеиваются и не записываются.
- **Лимиты**: сохраняется до 100 последних уникальных записей (до 50 МБ суммарных форматов на запись). Повторное копирование поднимает элемент наверх без дублирования.
